# Historical Android screenshots

The numbered PNGs in this directory show the original [Earshot Android app by HellzYeahh and contributors](https://github.com/HellzYeahh/earshot). They are preserved as upstream documentation and visual reference, with full credit to those authors.

This repository is an **AI-assisted iOS port attempt**. These Android screenshots do not show the iOS port. Actual iOS simulator screenshots and test evidence are described in [IOS_VALIDATION.md](../IOS_VALIDATION.md) and stored under `docs/ios-screenshots/` when exported.
