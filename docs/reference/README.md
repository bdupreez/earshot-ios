# Preserved reference work — credit and provenance

This directory is inherited research/reference material from the original [Earshot Android project by HellzYeahh and contributors](https://github.com/HellzYeahh/earshot). This fork is an **AI-assisted iOS port attempt**, and none of the reference work is claimed as new iOS authorship.

- `bosectl/`: reference implementation and research by [aaronsb/bosectl](https://github.com/aaronsb/bosectl), MIT, as copied and used by upstream Earshot. Keep original notices inside those files.
- `quietrebellion-android/`: [MadEyez/quietrebellion](https://github.com/MadEyez/quietrebellion), MIT; full licence retained alongside the reference source.
- `captures-galaxy/`: captures and observations documented by upstream Earshot on Android/Samsung hardware. These are **not iOS hardware test results**.

Vendored documents retain their original wording and notices. Current iOS scope and validation are in [the migration matrix](../IOS_MIGRATION.md) and [the iOS validation report](../IOS_VALIDATION.md). See [complete third-party credits](../../THIRD_PARTY_NOTICES.md).
